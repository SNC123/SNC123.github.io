# Hello VitePress

*April 4, 2026*

Welcome to my first blog post powered by [VitePress](https://vitepress.dev/)!

VitePress is a static site generator built on top of Vite and Vue 3, designed for creating documentation and blogs.

## Why VitePress?

- **Fast** — Instant server start and hot module replacement
- **Simple** — Write in Markdown, get a beautiful site
- **Powerful** — Full Vue component support inside Markdown

## Code Example

```javascript
// Hello from VitePress
const greet = (name) => `Hello, ${name}!`
console.log(greet('World'))
```
